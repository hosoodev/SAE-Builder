# Static Builder 시작하기

## 콘텐츠는 어디에 작성하나요?

`content/` 폴더에 Markdown 또는 MDX 파일을 만들고 Front Matter에 title, description, slug 등을 정의합니다.

## 빌드는 어떻게 하나요?

Builder 패키지를 컴파일한 뒤 `sae build`를 실행하면 정적 HTML, Sitemap, RSS, robots.txt와 최적화된 에셋이 `demo-dist/` 폴더에 생성됩니다.
