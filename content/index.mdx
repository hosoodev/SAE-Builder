# SEO/AEO Static Builder

이 페이지는 Markdown/MDX 콘텐츠, Front Matter, 템플릿, 자동 Sitemap, RSS와 정적 HTML 생성을 테스트하기 위한 예제입니다.

## 이 빌더는 무엇인가요?

SEO와 AEO가 중요한 콘텐츠형 웹사이트를 최소한의 JavaScript와 완전한 정적 HTML로 제작하기 위한 경량 빌드 시스템입니다.

## 왜 사용하는 건가요?

Next.js 같은 애플리케이션 프레임워크가 필요하지 않은 계산기, 변환기, 정보 사이트에서 빌드 구조와 SEO 규칙을 공통화할 수 있습니다.
